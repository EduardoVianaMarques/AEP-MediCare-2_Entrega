Documentação da API

Esta seção apresenta os recursos disponíveis no MediCare.

Autenticação

O sistema utiliza sessão HTTP para identificar o usuário autenticado.

Criar usuário 

POST /api/auth/cadastro

Login 

POST /api/auth/login

Usuário atual 

GET /api/auth/usuario

Logout 

POST /api/auth/logout

Medicamentos

Listar medicamentos 

GET /api/medicamentos

Cadastrar medicamento 

POST /api/medicamentos

Atualizar medicamento 

PUT /api/medicamentos/{id}

Excluir medicamento 

DELETE /api/medicamentos/{id}
