# Documentação do MediCare 0.4.0

O MediCare é uma prova de conceito da AEP que ajuda pacientes, familiares e cuidadores a organizar medicamentos, consultar horários e acompanhar o estoque. A aplicação se relaciona ao ODS 3, Saúde e Bem-Estar, pela organização das informações da rotina de cuidado.

| Documento | Conteúdo |
| --- | --- |
| [Arquitetura](ARQUITETURA.md) | Componentes, responsabilidades, estrutura do código, armazenamento e autenticação |
| [Fluxos](FLUXOS.md) | Cadastro, sessão, medicamentos, histórico, estoque, filtros e exportação |
| [API](API.md) | Rotas HTTP, dados enviados, códigos de resposta e exemplos |
| [Testes e resultados](TESTES.md) | Estratégia, execução local, CI e evidências verificadas |
| [Casos de teste](CASOS_DE_TESTE.md) | Catálogo dos cenários que existem no código |
| [Guia principal](../README.md) | Apresentação e instruções para executar o projeto |

A documentação descreve o código do MediCare 0.4.0 com o redesign de saúde. O [resultado da validação](TESTES.md#resultados-verificados) indica quais suítes foram executadas e quais ainda dependem de outro ambiente.
